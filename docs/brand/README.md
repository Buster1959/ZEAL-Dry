# ZEAL-Dry brand assets

ZEAL-Dry shares its brand family with [ZEAL-Heat](https://github.com/Buster1959/ZEAL-Heat)
— zone-based heating control for Home Assistant. Each product owns its own
mark and tagline; see [ZEAL-Heat's brand identity](https://github.com/Buster1959/ZEAL-Heat/blob/main/docs/BRANDING.md)
for that project's equivalent.

The approved master artwork is
[`ZEAL-Dry-logo-approved.png`](ZEAL-Dry-logo-approved.png). It is the sole
authoritative ZEAL-Dry logo and must not be redrawn or substituted with an SVG
approximation.

## Core presentation

Primary visual style:

- polished house outline with chimney
- three glossy blue water droplets, deliberately matched in visual weight to
  the central orange flame in the approved ZEAL-Heat mark
- flowing blue wave lines
- large ZEAL lettering with a `— DRY —` treatment
- clean geometric sans-serif typography with a practical, protective focus

Current brand line:

**INTELLIGENT MOISTURE PROTECTION FOR THE SPACES YOU LEAVE BEHIND.**

Short tagline:

**Keep it dry, not warm.**

the only repository logo file. It contains the approved logo without the
unintended black export footer.

Use the master PNG at a 240-pixel display width in Markdown headers. Do not set
a fixed height; preserving the natural aspect ratio prevents distortion.

The retired `ZEAL-Dry-logo.svg` is not a valid branding asset.

## Usage principle

ZEAL-Dry should always remain visually dominant on its own materials. Any
future ZEAL-Dry module or accessory should be presented as part of the
ZEAL-Dry product, not as an unrelated stand-alone brand — matching the
principle ZEAL-Heat's brand identity applies to its own FLOW/CONTROL/SCHEDULER
modules.
