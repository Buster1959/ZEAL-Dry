# ZEAL-Dry Documentation Images

This directory contains privacy-reviewed screenshots and diagrams used by the
ZEAL-Dry documentation.

## Current desktop captures

- `zeal-dry-three-zone-overview-desktop.png` — unified live status for three
  independently controlled zones.
- `zeal-dry-three-zone-overrides-desktop.png` — Property Protection, Occupied
  and Off controls shown together for all three zones.
- `zeal-dry-multi-zone-setup-desktop.png` — in-panel zone selection, Add zone,
  sensor and exclusive ACU assignment, and moisture-policy setup.

The captures use generic zone, entity and equipment names. They contain no
person names, property names, addresses, URLs, IP addresses, credentials,
tokens or identifiers from a real installation.

## Diagram

- `zeal-dry-moisture-risk-map.svg` — relationship between relative humidity,
  dew point, dew-point spread and the controller's risk response.

## Privacy review before commit

- Use generic zone, entity and equipment names.
- Remove addresses, person names, property names, URLs, IP addresses and device
  identifiers tied to a real installation.
- Check browser tabs, notifications, profile controls and sidebars.
- Do not show access tokens, credentials or unrelated Home Assistant data.
- Crop unused surrounding screen content.
- Give each image a descriptive lowercase filename.
